# Interview Atlas

An interactive study guide for data science interviews — built for people who learn by watching shapes move, not by reading walls of text.

---

## :material-book-open-variant: Parts

| | Part | What it covers |
|---|---|---|
| :material-chart-bell-curve-cumulative: | [**Part I — Statistics**](part1-statistics/index.md) | Distributions, hypothesis testing, sampling, Markov chains |
| :material-flask-outline: | [**Part II — Experimentation**](part2-experimentation/index.md) | A/B testing end to end: sample size, pitfalls, Bayesian vs frequentist |
| :material-scale-balance: | [**Part III — Causal Inference**](part3-causal/index.md) | DiD, RDD, propensity scores, meta-learners, synthetic control |
| :material-brain: | [**Part IV — Machine Learning**](part4-ml/index.md) | Loss functions, ensembles, clustering, neural nets, NLP |
| :material-code-braces: | [**Part V — Coding & Systems**](part5-coding/index.md) | DS&A, SQL, regex, git, ML system design |
